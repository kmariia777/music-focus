# Music Focus 🎧

A vibe-coded experiment: a focus-productivity web app that pairs a Pomodoro timer with royalty-free music stations, so you can work in timed sprints to a soundtrack.

Built with Replit Agent — an AI-assisted build I directed as a learning experiment. The code is AI-generated, not hand-written.

## What it does
- Pomodoro focus timer with daily goal tracking, session streaks, and a weekly session chart with history
- Three royalty-free music stations (Focus, Immerse, Drift — Kevin MacLeod tracks, CC BY 4.0, self-hosted) with playback and volume controls
- Task manager with priorities, status filters (Active/All/Done), and sharing
- AI coach chat (powered by your own OpenAI API key) for focus and productivity guidance
- Dark, purple-themed UI with a custom "brain-time" brand icon

## Try it
Run in Replit or clone and follow the project README for local setup.
