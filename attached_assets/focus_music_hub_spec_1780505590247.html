🎧 Focus Music Hub - Complete Specification

Comprehensive requirements document for the ADHD-friendly productivity application

📋 Project Overview

Purpose

Focus Music Hub is an ADHD-friendly productivity web application combining Pomodoro timer, music streaming, task management, and AI-assisted coaching.

Target Audience

  • ADHD individuals requiring structured productivity support
  • Professionals and students needing focus assistance
  • Music lovers wanting ambient music while working
  • Anyone using Pomodoro technique for productivity

Key Technologies

  • HTML5 + CSS3 + Vanilla JavaScript
  • No external dependencies or backend
  • Browser LocalStorage for data persistence
  • HTML5 Audio API for streaming
  • Web Speech API for voice input

⏱️ Core Features - Pomodoro Timer

Default Settings

  • Work: 25 minutes
  • Short Break: 5 minutes
  • Long Break: 15 minutes
  • Sessions Before Long Break: 4

Customization

  • Work Duration: 1-120 minutes
  • Short Break: 1-30 minutes
  • Long Break: 1-60 minutes
  • Preset Options: 25/5, 50/10, Custom

Display Requirements

  • Large timer display (72px desktop, 56px mobile)
  • Real-time countdown (MM:SS format)
  • Mode indicator (WORK MODE / BREAK MODE)
  • Session counter (Session 2/4)

Controls

  • Start/Pause button
  • Reset button
  • Skip button (advances to next phase)
  • Volume control slider

Statistics

  • Work sessions completed
  • Total focus time (in minutes)
  • Daily goal indicator (4 sessions)
  • Auto-reset at midnight

🎵 Music Streaming System

Stream Categories

Stream Icon Purpose
Focus 🧠 Upbeat/productive music
Chillout 🌊 Relaxing background music
Deep 🌌 Ambient/drone music

Audio Formats

  • Desktop: MP3 (primary), AAC (fallback)
  • iOS: AAC (primary), MP3 (fallback)
  • Android: MP3 (primary), AAC (fallback)

Features

  • Single stream plays at a time
  • Volume control (0-100%)
  • Mute toggle (speaker icon)
  • Auto-start with timer option
  • 7-bar animated equalizer (active stream only)
  • Active stream highlighted with teal border

📝 Task Management System

Task Status Levels

Status Color Description
Not Done 🔴 Red Default status for new tasks
In Progress 🟠 Orange Currently working on
Completed 🟢 Green Finished tasks

Task Operations

  • Create: Type + click + button or press Enter
  • Delete: Click × button
  • Update Status: Click colored buttons or checkbox
  • Auto-sort: Not Done → In Progress → Completed
  • Date Stamps: Automatic "Dec 25, 2024, 3:45 PM" format

Task Data Structure

{ id: 1, text: "Buy groceries", status: "not-done", createdAt: "2024-12-25T15:45:00Z", dateString: "Dec 25, 2024, 3:45 PM" }

🎤 Voice Input for Tasks

How It Works

  • Click 🎤 button next to + button
  • Browser listens to user speech
  • Speech converts to text
  • Task auto-adds after 1 second

Browser Support

Browser Support
Chrome ✅ Full support
Edge ✅ Full support
Safari ✅ iOS 14.5+
Firefox ❌ No support

Visual Feedback

  • Button turns red while listening
  • Input shows "🎤 Listening..."
  • Pulsing animation during recording
  • Clear error messages for failures

🤖 AI Agent Assistant

Appearance

  • Fixed bottom-right corner
  • 60px animated avatar (50px mobile)
  • Pulsing glow animation
  • Robot emoji (🤖)

Prompt Types

Type 1: Focus Session

Trigger: Idle 20+ minutes during work hours (9 AM - 6 PM)
Message: "Time for a focus session?"
Action: Starts Pomodoro timer

Type 2: Break Time

Trigger: 2+ work sessions completed
Message: "You've been working hard! Time for a break?"
Action: Starts break timer

Type 3: Add Task

Trigger: No tasks during morning (8 AM - 12 PM)
Message: "Would you like to add a new task?"
Action: Focuses task input

Check Frequency

  • Initial check: 30 seconds after load
  • Recurring: Every 2 minutes
  • Does not prompt while timer running
  • Respects last prompt time (no spam)

Settings Categories
